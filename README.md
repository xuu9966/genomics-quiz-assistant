# 章节自测复习助手（Chapter Quiz Assistant）

一份写给完全不懂命令行的同学的中文使用说明。看完本文，你应该能独立完成：拿到项目 → 装好环境 → 填好配置 → 双击一个脚本 → 在网页里填表开始复习 → 查看进度和结果。

> **最快入门**：装好 Python 3.10+ → 双击 `启动复习面板.bat` → 浏览器自动打开本机页面 → 在「复习启动」区域填学号、密码、章节、次数 → 点「开始复习」。其余章节都是把这个流程讲清楚，以及出问题时怎么办。

## 1. 项目简介与用途边界

**一句话定义**：章节自测复习助手是一个运行在你自己电脑上的本机网页工具，帮你按课程章节有计划地做自测、收集做错的题目、生成个人复习题库。

它解决的实际问题是：课程平台通常按「章节 → 若干次自测」组织练习，人工记住哪些章测过、每章测了几次、哪些题错过了很费劲。本工具把这些重复劳动自动化，并把进度和题目保存在你自己的电脑里。

**用途边界（请务必先读）**：

- 仅用于**个人课程自测与复习**。
- **不做多账号、不做班级共用**：单机单用户，没有账号体系。
- **不绕过监考、不绕过身份验证、不伪造成绩、不替代课程要求的正常考核**。
- 严格遵守你所在课程与平台的规定；如课程明确禁止自动化访问，请不要使用本工具。
- 界面用语一律是复习导向：「已复习 / 待复习 / 复习进度 / 复习题库 / 开始复习」。

工具只在你本机运行，面板只监听 `127.0.0.1`（本机回环），不监听 `0.0.0.0`，不做集中部署，你的账号和密码不会离开本机。

## 2. 环境与前置要求

| 项目 | 要求 | 说明 |
| ---- | ---- | ---- |
| 操作系统 | Windows 10 / Windows 11 | 首版推荐入口是 Windows 双击脚本 |
| Python | **3.10 或更高版本** | 双击脚本会自动检查版本，低于 3.10 会给出提示 |
| 浏览器 | 现代桌面浏览器（Edge / Chrome） | 无需安装任何浏览器插件 |
| 网络 | 运行机需能访问目标站点 | 若站点在内网，请先连接学校 VPN |
| 前端构建 | **不需要** | 无需 Node.js、无需 npm、无需打包 |
| 第三方 Python 包 | 当前无需安装 | 项目只用 Python 标准库 |

**安装 Python（如果电脑上还没有）**：

1. 打开 Python 官网 `https://www.python.org/downloads/`，下载 Windows 安装包（Python 3.10 及以上）。
2. 运行安装程序时，**务必勾选 `Add Python to PATH`**（这一步很关键，否则双击脚本找不到 Python）。
3. 安装完成后重新双击启动脚本即可，不需要重新登录或重启电脑（若已开着命令行窗口，关掉再开一个）。

**关于 `pip install -r requirements.txt`**：当前版本没有任何第三方依赖，这一步通常**不需要执行**。如果将来版本加入了依赖，按 README 或报错提示执行即可。

## 3. 获取项目

在你想存放项目的文件夹（例如 `D:\我的课程\`）里打开命令行，执行：

```bash
git clone https://github.com/xuu9966/genomics-quiz-assistant.git
```

然后进入项目目录：

```bash
cd genomics-quiz-assistant
```

你会看到类似这样的目录结构（重点是前两个文件）：

```text
genomics-quiz-assistant/
├─ 启动复习面板.bat        ← 双击这个文件启动（首版唯一推荐入口）
├─ README.md               ← 本说明文档
├─ config.example.json     ← 配置模板（不含真实账号密码）
├─ main.py                 ← 命令行入口（进阶用法才需要）
├─ webapp.py               ← 本机面板服务
├─ runtime.py              ← 网页启动的运行态管理
├─ static/                 ← 网页界面（index.html / app.js / app.css）
├─ docs/                   ← 产品与设计文档
└─ tests/                  ← 自动化测试
```

> **重要提醒**：`config.json`、`data/`、`logs/`、`exports/` 都已在 `.gitignore` 中忽略。**切勿把真实账号、密码、Cookie、会话标识提交进 Git 仓库**。配置模板 `config.example.json` 只预置了课程站点地址，**不含任何账号、密码**，请保持这样。

如果你不会用 Git，也可以直接下载仓库的 ZIP 压缩包并解压，效果一样；后续更新时重新下载即可。

## 4. 配置模板

**好消息：这个项目已经预配好站点地址，你基本不用改任何文件。**

首次双击启动脚本时，脚本会**自动**把 `config.example.json` 复制成 `config.json`（如果 `config.json` 还不存在）。里面已填好本课程的站点地址，直接可用。

如果你想看看它长什么样，用记事本打开 `config.json` 会看到类似内容：

```json
{
  "base_url": "http://10.20.212.33:5000/",
  "username": "",
  "password_env": "CQA_PASSWORD",
  "chapters": [],
  "limit": 10,
  "repeat_default": 3,
  "repeat_overrides": {},
  "model": "deepseek-v4-flash",
  "paper": { "single_count": 5, "multi_count": 5, "score_per": 10, "duration": 0 },
  "request_interval_sec": 2.0,
  "retry_times": 3,
  "retry_backoff_sec": 2.0,
  "task_timeout_sec": 180,
  "score_poll_interval_sec": 5,
  "score_poll_timeout_sec": 90,
  "web": { "host": "127.0.0.1", "port": 8765, "poll_sec": 3, "status_color": false },
  "paths": { "data_dir": "data", "log_dir": "logs", "export_dir": "exports" }
}
```

**绝大多数同学：什么都不用改，双击脚本 → 网页填学号密码 → 开始复习即可。**

只有下面两种情况才需要改动：

- `base_url`：已预填本课程站点地址。**只有当你访问的不是这门课的站点时**才需要改（必须以 `http://` 或 `https://` 开头）。
- `username`：留空即可。学号在网页表单里填，比你在这里填更优先、更安全。

其余参数（`model`、`paper`、`request_interval_sec`、超时重试、`web`、`paths`）保持模板默认即可，一般不用动。

**关于密码，请记住三条**：

1. **密码不要写进 `config.json`**。文件里不应该出现任何密码字段的值。
2. 双击脚本走网页路径时，密码在网页上现填，只在本机内存里活到本次执行结束。
3. 环境变量 `CQA_PASSWORD` 只在**命令行路径**（`python main.py run`）才需要设置；走双击网页路径**不需要设置它**。

`chapters`、`repeat_default`、`repeat_overrides`、`limit` 在 `config.json` 里是「模板默认值」，网页上填的值会覆盖它们；网页没填的字段会回落到这里的默认值。网页上的任何修改都**不会写回**这个文件。

改完 `config.json` 保存即可，不需要重启（下次双击启动时会读取）。

## 5. 网页启动步骤（主路径）

这是给同学用的**唯一推荐路径**。全程不需要敲任何命令。

**第 1 步：双击启动**

在文件管理器里找到项目根目录的 `启动复习面板.bat`，**双击**。会弹出一个黑色（或深色）窗口，窗口里显示「章节自测复习助手 · 本机面板」等信息。

**第 2 步：保持黑窗口开着**

这个黑窗口就是本机面板进程。**请保持它开启**：关闭它等于关闭面板，后台任务也会随进程退出。

**第 3 步：浏览器打开页面**

脚本会在面板就绪后自动用默认浏览器打开 `http://127.0.0.1:8765/`。

- 如果 8765 端口被别的程序占用，程序会自动顺延到 8765 之后的端口（最多试 20 个）。
- 这种情况下**以黑窗口里显示的地址为准**，例如 `http://127.0.0.1:8767/`。
- 如果浏览器没有自动打开，手动复制黑窗口显示的地址到浏览器地址栏访问即可。

**第 4 步：填写启动表单**

页面顶部有一个始终可见的「复习启动」区域，从上到下填：

- 学号
- 密码（密码框，输入时不显示明文）
- 章节（勾选；有「全选 / 全不选」按钮）
- 每章次数（统一次数）
- 限量（0 表示全量）
- 按章覆盖（可选，折叠在「按章覆盖」小结里）

字段含义见下一章。

**第 5 步：点「开始复习」**

点击后按钮会短暂禁用，防止连点。页面上会提示「已启动」，运行态变为「启动中」→「执行中」。你可以在同一页面持续看进度。

**几个要强调的点**：

- **面板只在本机可访问**：别的电脑访问不到你的 `127.0.0.1`，这是刻意设计的安全边界。
- **密码只在网页填**：不会写进文件、不会显示在页面上、不会写进日志或导出文件。
- **关掉浏览器页面不会中断后台执行**：任务在面板进程里跑；但**不要关黑窗口**。
- **重复点击不会启动第二轮**：已有任务在跑时，会提示「已有复习任务在执行中，请等待完成」。

## 6. 表单填写说明

| 字段 | 必填 | 含义与填写建议 |
| ---- | ---- | -------------- |
| 学号 | 是 | 对应平台登录用的学号（内部字段 `username`）。留空会提示「学号不能为空」。 |
| 密码 | 是 | 平台登录密码，密码框不回显。只在本次执行中使用，关闭页面或重启程序后需要重新填。 |
| 章节 | 至少 1 章 | 8 大章多选：`0_预习`、`1_绪论`、`2_测序`、`3_组装`、`4_注释`、`5_数据库`、`6_实验`、`9_复习`。可用「全选 / 全不选」快速操作。不选时后端按「全部大章」处理。 |
| 每章次数 | 是 | 统一给每个选中章设定自测次数，范围 1~99。例如填 3 表示每章做 3 次。 |
| 按章覆盖 | 否 | 给特定章单独设次数，留空表示用「每章次数」。例如「每章次数 = 3」但给 `2_测序` 填 5，则该章做 5 次、其余章做 3 次。 |
| 限量 | 是 | **本次纳入的大章数**，不是题目数。例如填 2 表示本次只处理 2 个大章；填 **0 表示全量**（所有选中章）。 |

**来源标签怎么看**：

页面会显示本次参数快照，每项后面有一个小标签：

- 「模板默认」：这个值来自 `config.json` 模板，网页没改。
- 「环境变量」：这个值来自环境变量（如 `CQA_USERNAME`）。
- 「网页修改」：这个值来自你刚才在网页上填的内容，优先级最高。

每个章节还会显示本次次数和来源：「默认 M」表示用的是统一次数，「覆盖 M」表示用了按章覆盖的值。

**优先级规则**：网页输入 > 环境变量 > `config.json` 模板默认。网页填的值只对这一次执行生效，**不会写回配置文件**。

**校验提示**：学号或密码为空、次数填 0 或超过 99、限量填负数、章节名不合法，都会给出一句可读的中文提示，不会弹出一堆英文堆栈。

**关于「限量 = 0（全量）」**：全量或单次次数较大时，页面会弹出一次确认提示，防止误操作导致长时间运行。点「确定」才会提交。

## 7. 查看进度与结果

页面有三个标签页，从左到右：

**① 总览**

- 顶部指标卡：执行单元总数、已完成数、平均分、满分数、失败数。
- 总体进度条与各章进度条。
- 得分明细表：按「大章 / 第 k 次」列出状态与得分。
- 运行日志尾部（可复制，便于反馈问题）。
- 顶部「本次运行」区显示五相位状态与脱敏参数快照。

**② 复习记录**

- 可按关键词、状态、大章、第 k 次筛选。
- 勾选行后可「重新执行所选」；点击某行可看失败摘要与处理建议。
- 可导出 CSV（给表格软件打开）。
- 失败摘要只显示错误类型与可读说明，不含任何凭据。

**③ 复习题库**

- 从结果页与评阅总结自动汇聚的题目，按题干去重。
- 可按关键词、题型、大章筛选；支持导出 HTML / Markdown / JSON 三种格式。
- **建议先自测，再展开解析**。题库仅用于个人复习，不分发、不商用。
- 含图片题会标记「[含图片]」。

**运行态五种状态**：

| 状态 | 含义 |
| ---- | ---- |
| 未启动 | 面板已开，但还没提交过启动表单 |
| 启动中 | 正在合并配置、登录、解析章节、生成计划 |
| 执行中 | 计划已生成，正在逐个执行自测 |
| 已完成 | 本轮全部执行单元处理完毕 |
| 失败 | 启动/登录/规划阶段中止；具体原因见错误摘要（已脱敏） |

**刷新与断点续跑**：页面每 3 秒左右自动刷新（不超过 10 秒），不需要手动刷新。已经成功的执行单元不会重复组卷；中途退出后再次启动，会从没完成的单元继续。

## 8. 常见问题（FAQ）

**Q：双击脚本后黑窗口一闪而过？**
A：脚本在 Python 未找到、配置缺失等情况下会 `pause` 停住并显示原因。如果确实闪退，请手动在该目录打开命令行执行 `python main.py serve --open-browser` 看报错，或截图反馈。

**Q：提示「未找到 Python 3.10+」？**
A：说明没装 Python 或装的时候没勾选 `Add Python to PATH`。按第 2 章重装并勾选，然后重新双击。

**Q：浏览器打不开页面 / 显示拒绝访问？**
A：面板必须在本机浏览器打开，地址是 `http://127.0.0.1:<端口>/`。请确认黑窗口保持开启。如果换端口了，以窗口里显示的地址为准。

**Q：提示端口占用怎么办？**
A：不用管，程序会自动顺延到 8765 之后的端口。看黑窗口显示的「复习控制台已启动：http://127.0.0.1:xxxx/」，用那个地址访问。

**Q：双击后浏览器没自动打开？**
A：少数系统默认浏览器设置可能导致自动打开失败。手动复制黑窗口里的地址到浏览器即可，功能完全一样。

**Q：登录失败 / 提示用户名或密码错误？**
A：依次核对：网页上填的学号密码是否正确；`config.json` 里的 `base_url` 是否正确（要以 `http://` 或 `https://` 开头）；运行机是否能访问该站点（内网站点需先连 VPN）；账号是否被平台锁定。

**Q：提示 429 / 请求过于频繁？**
A：程序内置了退避重试，会自动等待后重试。若持续限流，请把 `config.json` 里的 `request_interval_sec` 调大（例如 3 或 5）后再启动。

**Q：出分很慢 / 一直显示评阅中？**
A：平台出分需要时间。程序按 `score_poll_timeout_sec`（默认 90 秒）等待，超时会把该单元记为失败并记录「出分超时」摘要。可以稍后对该行点「重新执行」。

**Q：提示配置损坏 / 不是合法 JSON？**
A：用记事本打开 `config.json` 检查是否少了逗号、引号或括号。最省事的办法是删掉 `config.json`，重新双击脚本让它从模板再生成一份，然后重新填固定参数。

**Q：连点「开始复习」没反应？**
A：这是正常的幂等保护——已有任务在执行中，按钮会禁用并提示「已有复习任务在执行中，请等待完成」。不会重复组卷，也不会多消耗平台配额。

**Q：关掉浏览器页面，任务会中断吗？**
A：不会。任务在面板进程里跑，页面只是看进度。但**不要关闭那个黑窗口**。

**Q：题库导出文件在哪里？**
A：默认在 `exports/` 目录（可在 `config.json` 的 `paths.export_dir` 改）。复习记录与状态在 `data/state.json`，日志在 `logs/app.log`。

**Q：换了一个同学用这台电脑，怎么清理数据？**
A：停止面板（关黑窗口），删除 `data/` 目录后重新启动。这样旧的执行记录和参数快照就不会混在一起。

**Q：重启程序后，还要重新填密码吗？**
A：要。密码只在本次进程内存中保存，不落盘，这是刻意的安全设计。任务进度仍保留在 `data/state.json`，不会丢。

## 9. 合规边界与伦理

- **用途限定**：仅个人课程自测与复习，不分发、不商用、不用于任何形式的成绩造假。
- **不绕过规则**：不绕过监考、身份验证、防作弊机制或课程平台的技术保护措施。
- **不伪造成绩**：工具只记录你真实完成的自测结果，不修改、不伪造平台数据。
- **先自测、后看解析**：请自己先独立作答，再展开题库解析；把题库当作复盘材料，而不是标准答案来源。
- **尊重课程规定**：如课程或平台明确禁止自动化访问，请停止使用并遵守课程要求。
- **数据仅存本机**：账号、密码、记录、题库都只在你的电脑和内存中流转；面板只监听回环地址，不对外暴露。

界面和文档一律使用复习导向用语（已复习 / 待复习 / 复习进度 / 复习题库），保持学术简洁风格：黑白灰配色、细线分隔、状态色默认关闭、可打印可复制。

## 10. GitHub 上传注意事项

上传仓库前请做一次「凭据体检」，避免把自己的账号信息带进公开仓库：

1. **确认忽略规则生效**：`.gitignore` 已忽略 `config.json`、`data/`、`logs/`、`exports/`。执行 `git status` 确认这些路径不在待提交列表里。
2. **确认模板无凭据**：`config.example.json` 只预置了课程站点地址（`base_url`），**不含任何账号、密码、Cookie**；不要往里填真实学号或密码。
3. **确认源码无真实值**：不要在任何 `.py`、`.js`、`.html`、`.bat` 文件里硬编码账号、密码、Cookie 或会话标识。
4. **确认文档示例无真实值**：README 和 `docs/` 里的示例地址都用 `example.invalid` 一类占位域名。
5. **密码只在网页输入、不落盘**：运行时的密码只存在于本机内存与回环请求体中，不会写进被版本控制的文件。
6. **可正常入库的文件**：`启动复习面板.bat` 与 `README.md` 可以正常提交；它们不含任何真实凭据。

如果你之前不小心把含真实信息的文件提交过，请在分享仓库前从 Git 历史中彻底清除，并立即修改对应平台的密码。
