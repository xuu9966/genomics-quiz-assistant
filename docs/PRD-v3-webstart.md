## 0. 变更性质与用户已拍板决策

这是一次**启动体验的增量增强**：把"改 config.json + 命令行 `python main.py run` + 环境变量/无回显输密码"的三步门槛，收敛为"打开本机网页 → 填表 → 点按钮"。产品要上传 GitHub 给同学使用，目标是**降低不懂命令行同学的使用门槛**。

**用户已拍板、不可推翻的决策：**

| # | 决策 | 结论 |
| - | ---- | ---- |
| 1 | 使用方式 | 同学**各自 clone 到本地、各自运行**；面板**继续只监听 127.0.0.1（本机回环）**；不做集中部署、不监听 0.0.0.0；**凭据不出本机** |
| 2 | 表单范围 | 网页填写 **学号 + 密码 + 章节（可调）+ 每章次数（可调）+ 限量**；站点地址等固定参数**预置在 config.json 模板，不放到网页** |
| 3 | README | 提供**详细中文 README**，面向不懂命令行的同学：clone、Python 环境要求、配置说明、网页启动步骤、常见问题 |
| 4 | 合规 | 平台允许自动化访问无需报备、题库允许导出个人保存（v2 §6 已确认）；**产品自身伦理边界、复习导向文案、学术简洁风 UI 全部保留** |

## 3. 功能需求（沿用 FR 编号，标注新增 / 变更）

### FR-8 网页启动【新增 · P0】

**FR-8.1 启动表单字段清单**（在面板新增"复习启动"区域，可置于总览视图或独立标签；具体形态由架构定）

| 字段 | 必填 | 默认值来源 | 说明 / 校验 |
| ---- | ---- | --------- | ----------- |
| 学号 | 是 | config.json 模板 `username` | 文本输入；对应现有 `username` 字段（见待确认 #2）；空值给可读错误 |
| 密码 | 是 | 不预置 | **密码框**呈现、不回显；不随页面/状态接口回传；仅本次登录使用（见 FR-7.3） |
| 章节选择 | 是（至少 1 章） | 模板 `chapters` | 从顶层大章清单多选；清单取核验 §7.4 的 8 个大章（0_预习/1_绪论/2_测序/3_组装/4_注释/5_数据库/6_实验/9_复习）；提供"全选/全不选" |
| 每章次数 | 是 | 模板 `repeat_default`（默认 3） | 正整数，1~99（沿用 FR-1.5 / REPEAT_LIMIT） |
| 按章覆盖（可选） | 否 | 模板 `repeat_overrides` | 可为单个大章设不同次数；沿用 v2 覆盖规则（命中 override 用覆盖值，否则用默认次数）。若首版先不在网页编辑，见待确认 #3 |
| 限量 | 是 | 模板 `limit`（默认 10） | 非负整数，**0 = 全量**；语义沿用 v2 = 本次纳入的大章数 |
| 默认/覆盖来源展示 | — | 自动 | 紧邻字段显示每项来源标签（**模板默认 / 网页修改**）；每个章节显示本次次数及其来源（**默认 M / 覆盖 M**），供启动前确认（承接 FR-2.3） |

> 站点地址、模型、组卷参数、超时/重试、日志/导出目录、web 监听等**固定参数不在表单出现**，只从 config.json 模板读取（拍板 2）。

**FR-8.2 启动动作**：点击"开始复习"后，后端使用表单中的**学号 + 密码**登录，按表单的**章节 / 每章次数 / 按章覆盖 / 限量**生成 v2 计划（`大章 × 第 k 次`，唯一键 `大章节点id::第k次`），交给执行器执行。固定参数仍取模板。交互为"向本机面板提交表单"，**不规定具体接口路径**。

**FR-8.3 参数校验**：提交前校验学号/密码非空、章节合法、次数与限量在范围内；非法值给**可读错误、不输出堆栈**（沿用 FR-1.2 / FR-1.5 / config 校验口径）。

**FR-8.4 执行期面板持续可用**：启动后面板立即可用、持续展示本次计划与进度（沿用 FR-6.4）；关闭浏览器页面**不中断**后台执行（沿用 v2）。

**FR-8.5 启动幂等与重复点击处理【新增】**：
- 后端维护**单一运行实例与运行态**；已有未完成执行（启动中/执行中）时，再次点"开始复习"**不得新建第二个执行线程**，应返回明确提示"已有复习任务在执行中"。
- 前端在启动请求处理期间**禁用启动按钮**，收到明确状态反馈后再恢复，防网络抖动连点。
- 幂等判定以"是否存在活跃执行流程/运行态"为准，**不按参数内容判定**（同一进程同一时刻只应有一轮执行）。
- P1（可后置）：提供"停止当前任务 / 排队重启"，使用户能在当前任务结束后用新参数重跑；首版可仅提示"请等待当前任务完成"。

**FR-8.6 启动反馈**：提交后前端给出明确反馈——"已启动"、"已有任务在执行中"或校验错误；运行态变化在面板可见（见 FR-6.5）。

## 4. 验收标准变更

### 4.1 新增验收点（供 QA 增补用例，可勾选）

- [ ] **网页启动闭环**：clone 后仅通过网页填写学号/密码/章节/次数/限量并点击"开始复习"即可启动执行，无需命令行参数与环境变量。
- [ ] **表单字段齐全**：含学号、密码（密码框不回显）、章节多选（8 大章来自核验 §7.4）、每章次数、按章覆盖、限量，以及每项"模板默认/网页修改"来源标签。
- [ ] **参数即时生效**：点击启动后后端用刚填学号密码登录，并按刚填章节/次数/覆盖/限量生成计划（执行单元数 = Σ每章次数，`limit` 按大章数生效），无需改 config.json 或重启命令行。
- [ ] **配置优先级与不回写**：网页输入覆盖模板默认；未填字段回落模板默认；网页启动后 config.json 内容保持不变（未被回写）。
- [ ] **固定参数不从表单读取**：站点地址/模型/组卷/超时重试/目录仍取模板；表单无这些字段。
- [ ] **面板执行期可用**：启动后面板立即可用、持续显示进度；关闭页面后台不中断（沿用 FR-6.4）。
- [ ] **运行态与快照展示**：总览显示运行态与脱敏参数快照；"本次范围"反映网页本次提交值并显示来源标签；快照中无密码。
- [ ] **凭据安全（网页路径）**：密码经本机回环提交、仅内存持有；config.json / 日志 / state.json / 状态接口响应 / CSV / 题库导出物中均无密码明文；前端不回显、不写 localStorage/sessionStorage。
- [ ] **回环约束**：面板仅监听 127.0.0.1，未监听 0.0.0.0，非本机不可访问。
- [ ] **启动幂等**：连续多次点击"开始复习"或重复提交，只启动一轮执行；提示"已有任务在执行中"；不重复组卷、不重复消耗配额。
- [ ] **参数校验**：空学号/密码、非法章节、越界次数/限量给可读错误、无堆栈输出。
- [ ] **README**：含环境要求、clone、配置、网页启动步骤、填写说明、常见问题、合规边界、GitHub 注意事项；示例无真实凭据。

### 4.2 v2 验收点保持不变（明确声明，QA 不改动）

- v2 大章任务模型全部验收点：每章刷 M 次、按章覆盖生效、唯一键 `大章节点id::第k次`、同章计数同步、跨章计数独立、中途续跑补齐、大章清单展示。
- 成功指标：M1（首次配置 ≤2 分钟）、M2（完成率 ≥95%，分母 = 执行单元总数）、M3（单套发起→出分 ≤3 分钟）、M4（成绩视图延迟 ≤10 秒）、M5（重复生成率 0%）、M6（题库题数 >0 且去重）。
- FR-3 执行引擎（组卷/作答/交卷/评阅、节流退避、不并发）、FR-4 监控恢复（状态持久化、断点续跑、日志不含凭据）、FR-5 题库（采集/去重/三格式导出/图片题）。
- FR-6.1~6.3 三视图既有能力、刷新 ≤10s；FR-6.4 执行期可用。
- FR-7.1 既有安全项、FR-7.2 回环监听。
- 合规与伦理边界、复习导向文案（"已复习/待复习/复习进度/复习题库"，无"刷分"措辞）、学术简洁风 UI（黑白灰+细线、状态色默认关闭、可打印可复制）。
