## 1. 产品目标与范围

### 1.1 一句话定义

一款帮助学生在课程平台上**批量完成章节自测、集中查看成绩、并把散落题目整理成可离线复习题库**的本地工具。以复习为向导，不做任何绕过监考或伪造成绩的设计。

### 1.2 产品目标（三个正交目标）

| 目标 | 描述 | 对应场景 |
| ---- | ---- | ------- |
| G1 自动化执行 | 一次配置、一次启动，自动完成选定范围内的章节自测；支持断点续跑与异常后继续 | A、B |
| G2 可视化可追溯 | 随时看到整体进度、各章完成度、每套得分与异常原因，可诊断、可复盘 | A、B、D |
| G3 题库沉淀与复习 | 把平台散落的题目/答案/解析汇聚为可搜索、可导出、按题干去重的本地复习题库 | C |

> 安全与隐私（凭据保护、本地边界）为**贯穿性硬约束**，不作为独立目标，落入 FR-7 与第 1.4 节。

### 1.3 MVP 边界

**包含（P0）**

- 账号配置与本地安全保存（无回显输入、环境变量覆盖、版本控制忽略）
- 课程目录**递归**解析与任务计划生成（含全量任务计划展示）
- 自动组卷 → 获取题目 → 自动作答 → 交卷 → 等待评阅 → 成绩回收
- 进度 / 成绩 / 异常的本地 Web 可视化（面板执行期间持续可用）
- 断点续跑与强制重跑
- 题库汇聚、题干去重、HTML / Markdown / JSON 三格式导出
- 本地日志与 CSV 导出

**不包含（首版明确排除）**

- 多用户、多账号切换、班级共用
- 云端同步、跨设备恢复、云端托管
- 图形化安装器、自动更新、桌面端打包
- 答题引擎完整插件化（首版仅要求作答逻辑与平台 HTTP 逻辑分离、预留替换点）
- 平台改版的自动适配
- 移动端适配（面板以桌面浏览器为主）
- 任何绕过监考 / 伪造成绩 / 规避平台规则的能力

### 1.4 合规与伦理边界（复习导向，不可协商）

| 约束 | 说明 |
| ---- | ---- |
| 用途限定 | 仅用于个人课程自测与复习；用户须遵守所在课程与平台规定 |
| 不做的事 | 不绕过身份验证、权限校验、防作弊机制；不伪造成绩；不修改学习记录；不绕过监考 |
| 界面文案 | 统一使用**复习导向**措辞：如「已复习 / 待复习 / 复习进度 / 复习题库」；不使用「刷分 / 刷壳 / 满分达成」等鼓励只刷分的表述 |
| 作答定位 | 平台问答能力仅作为自测作答来源；题库是**复习材料不是答案替身**，界面提示"先自测、后看解析" |
| 凭据责任 | 账号密码由用户自行提供并保管；不进入仓库、日志、导出物 |
| 题库使用 | 仅个人复习，不公开分发、不商用 |

> 注：接口提交按平台既定契约传参（属正常集成行为），不涉及、不讨论任何监考规避场景。

### 1.5 成功指标（含现实性修正，详见 4.2）

| 指标 | 确认目标 | 备注 |
| ---- | ------- | ---- |
| 首次配置耗时 | ≤ 2 分钟 | 与规模无关，保持 |
| 选定范围内任务完成率 | ≥ 95%（排除平台不可用） | **分母改为"限量后的任务集"**，非全量 796 |
| 单套自测从发起到出分 | ≤ 3 分钟（不含平台排队） | 紧张但基本现实，超时记失败不无限等待 |
| 成绩视图更新延迟 | ≤ 10 秒 | 保持 |
| 断点续跑后重复生成率 | 0% | 796 规模下为**关键指标**，强制唯一键持久化 |
| 题库导出可搜索题数 | > 0，且按题干去重 | 保持 |

## 3. 需求池与优先级

### 3.1 优先级定义

- **P0（必须有）**：MVP 核心闭环，缺失则场景跑不通或指标无法达成。
- **P1（应该有）**：体验增强与稳健性提升，MVP 后可快速跟进。
- **P2（可以有）**：锦上添花 / 依赖外部确认，排期靠后。

### 3.2 FR-1 ~ FR-7 优先级映射（全部 P0，含理由）

| FR | 需求 | 优先级 | 理由 |
| -- | ---- | ----- | ---- |
| FR-1 | 账户与配置（无回显、校验、环境变量覆盖） | **P0** | 一切流程的入口；凭据安全是硬约束（FR-7 配套），缺它无法启动 |
| FR-2 | 任务规划（递归目录发现、范围筛选、限量、强制重跑） | **P0** | 796 文件规模下，"限量执行"与"递归遍历"直接决定可用性（见 4.1） |
| FR-3 | 自动作答执行引擎（组卷/作答/交卷/评阅、节流重试） | **P0** | G1 核心；429 限流客观存在，重试是完成率 ≥95% 的前提 |
| FR-4 | 执行监控与恢复（状态持久化、断点续跑、日志） | **P0** | G1 恢复能力 + 重复生成率 0% 的载体；长流程中断高发 |
| FR-5 | 题库汇聚与复习（采集/去重/三格式导出/图片题） | **P0** | G3 核心，场景 C 的载体 |
| FR-6 | 可视化控制台（总览/记录/题库/执行期可用） | **P0** | G2 核心；场景 A/B/D 与"成绩视图延迟≤10秒""各章完成率"等指标均依赖它，缺它核心闭环不完整 |
| FR-7 | 安全与隐私（凭据处理、本机回环、本地边界） | **P0** | 合规红线，草稿 1.4 目标 4 与第 9 节的落点 |

> 结论：FR-1~FR-7 **全部为 P0**。核心闭环 = 配置 → 规划 → 执行 → 监控恢复 → 题库 → 可视化，安全贯穿。P1/P2 用于承接草稿第 11 节"后续迭代"与开放问题中需延后的项。

### 3.3 P1 / P2 迭代项（来自草稿第 11 节及开放问题）

| 迭代项 | 优先级 | 来源 | 理由 |
| ---- | ----- | ---- | ---- |
| 面板先行、后台执行的启动体验优化 | P1 | 草稿 §11 | 体验增强，非功能缺失；FR-6.4「执行期面板可用/展示完整计划」已保 P0 |

## 4. 关键澄清与决策

### 4.1 796 文件规模：影响与产品决策

核验记录修正：整棵知识树 **796 个 `.md` 文件**，分布在各层节点（不只顶层），远超草稿"26 个"估计。

| 决策点 | 确认结论 | 产品理由 |
| ---- | ------- | ------- |
| 目录解析 | **递归遍历整棵树**；`tree` 兼容对象/数组两种形态；子文件夹节点也有独立 id | 文件散布各层，只读顶层 `files` 会大量漏任务，直接破坏 FR-2.1 与完成率 |
| 任务唯一标识 | **节点 id + 文件路径** 组合（如 `20260907180845_0001` + `2_测序\基因组测序.md`） | 同名文件可出现在不同章节，单用路径会碰撞，导致断点续跑错判（违反重复生成率 0%） |
| 章节筛选 | 按**文件路径顶层前缀**（如 `2_测序\`）或**节点归属**；章节参数同时支持数字编号与名称前缀（兼容"自主学习""9_复习"等无数字/带数字节点） | 顶层节点命名不统一，仅靠数字编号会漏掉"自主学习"等节点 |
| **限量执行** | **P0 核心参数**：默认限量（建议默认 10 套），用户可显式选全量并二次确认 | 见下方"为什么限量是可用性关键" |
| 并发/节流 | 禁止并发请求同一接口；退避重试、间隔可配置 | 平台返回 429，796 任务下并发会触发大面积失败 |

**为什么"限量执行"是可用性关键**：单套自测约 40–180 秒（生成 30–90s + 评阅 10–90s），796 套串行约 **13–40 小时**，全量一次跑既不现实也极易触发 429。没有限量参数，用户面对"要么跑几十小时、要么触发限流"的两难，MVP 实际不可用。因此限量参数不是优化项，而是 P0 可用性保障。

### 4.2 成功指标现实性判断与建议

| 指标 | 目标 | 796 规模下判断 | 建议 |
| ---- | ---- | ------------- | ---- |
| 首次配置耗时 ≤2 分钟 | 保持 | ✅ 现实，与文件规模无关（配置只填地址/账号/范围/参数） | 配置阶段**只做轻量校验，不遍历整棵树**；目录解析后置到任务规划并给进度提示，避免配置卡顿 |
| 任务完成率 ≥95% | 修正 | ⚠️ 原分母"选定范围"在全量 796 下含义不清 | **分母改为"限量后实际纳入的任务集"**；配合 429 退避重试；平台不可用不计入分母 |
| 单套发起→出分 ≤3 分钟 | 保持但标注 | ⚠️ 紧张：最坏 90+90=180s，正好卡边界 | 明确"不含平台排队"；设超时上限，超时记失败而非无限等待；面板对"评阅中"给明确状态 |
| 成绩视图延迟 ≤10 秒 | 保持 | ✅ 现实 | 本地状态读取 + 轮询/推送均可满足；由架构师定方案 |
| 重复生成率 0% | 保持并强化 | ✅ 现实但**关键**：796 规模中断概率高 | 强制以"节点 id + 文件路径"唯一键持久化状态；组卷前先查完成记录 |
| 题库题数 >0 且去重 | 保持 | ✅ 现实 | MD5 题干去重（附录 A.10），多来源合并解析 |

> 补充判断：不建议在验收中要求"单次跑完全部 796 套"。应把"限量执行 + 多次续跑"作为标准使用方式写进使用引导。

### 4.3 其他产品决策

| 事项 | 决策 |
| ---- | ---- |
| 站点地址 | 内网地址（见草稿附录 A.1），运行机须在同一网络或已接入 VPN；地址可配置、不写死 |
| 外部参数 | 站点地址、章节范围、模型名、等待时长、重试次数、限量数**全部可配置** |
| 数据生命周期 | 执行记录长期保留可手动清理；日志滚动保留避免无限增长；导出物由用户管理 |
| 作答来源 | 优先复用平台问答能力；作答逻辑与平台 HTTP 逻辑分离，不可用时可替换（P0 留点、P1 做插件） |

## 5. UI 设计稿

### 5.1 视觉总则（学术简洁风，优先级高于草稿 5.2）

- **配色**：黑白灰为主；细线（1px）分区；克制、正式，无渐变、无大色块、无彩色标签。
- **状态表达**：以**灰阶层次 + 文字标签 + 符号/边框样式**为主；状态色为**可选增强，默认关闭**（提供"纯灰阶"默认主题）。详见 5.5。
- **信息密度**：信息密度优先，装饰从简；清晰字体层级、留白、细线划区。
- **可打印可复制**：表格与题目/解析区必须可选中复制、打印友好（无背景色依赖）。
- **文案**：复习导向（见 1.4），全过程避免"刷分"类措辞。

### 5.5 状态表达规范（默认纯灰阶）

## 6. 运行环境提示（非技术栈规定）

以下为**约束提示**供架构师参考，不构成技术选型：

- 必须支持**本地运行**，无需复杂构建环境（目标用户时间有限、可借助 AI 助手运行）。
- Web 控制台**仅监听本机回环地址**（FR-7.2）。
- 兼容主流桌面操作系统与现代浏览器；面板以桌面为主。
- 运行机需与目标内网站点同网络或接入 VPN。
- 凭据通过无回显输入 / 环境变量提供，配置文件默认被版本控制忽略。

## 8. 验收标准索引（供 QA 编写用例，可勾选）

### A. 成功指标验收

- [ ] **M1 首次配置耗时 ≤ 2 分钟**：从进入配置到保存成功，配置阶段不遍历整棵树。
- [ ] **M2 任务完成率 ≥ 95%**：分母 = 限量后任务集，排除平台不可用；统计成功/总数。
- [ ] **M3 单套发起→出分 ≤ 3 分钟**（不含平台排队）：超时记失败，不无限等待。
- [ ] **M4 成绩视图更新延迟 ≤ 10 秒**：任务状态变更后面板可见该变化。
- [ ] **M5 断点续跑重复生成率 0%**：中断后续跑，已完成任务的组卷接口调用次数为 0。
- [ ] **M6 题库可搜索题数 > 0 且按题干去重**：导出后无重复题干。

### B. 功能需求验收

**FR-1 账户与配置**
- [ ] FR-1.1 密码无回显；配置本地保存且默认不入版本控制；模板无真实凭据；支持环境变量覆盖。
- [ ] FR-1.2 缺账号/密码时提示并停止；章节范围非法给具体错误；配置损坏给可读错误、不输出堆栈。

**FR-2 任务规划**
- [ ] FR-2.1 递归遍历整棵树（796 文件不漏）；`tree` 为对象/数组均可解析；任务含章节、文件名、唯一标识（节点 id + 路径）；解析失败提示"页面结构可能变化"而非空清单。
- [ ] FR-2.2 章节参数正确筛选（数字编号 + 名称前缀）；限量按筛选后顺序生效；强制重跑忽略本地记录。

**FR-3 执行引擎**
- [ ] FR-3.1 区分单选/多选；提交格式可被平台评阅成功；单任务失败不影响后续；每任务生成唯一会话标识。
- [ ] FR-3.2 作答逻辑与 HTTP 逻辑分离；结果可解析为明确选项，无法解析记失败而非猜测；保留原始返回。
- [ ] FR-3.3 限流/服务端错误自动重试（次数间隔可配置）；重试耗尽记失败并继续；不并发请求同一接口。

**FR-4 监控与恢复**
- [ ] FR-4.1 状态含待执行/执行中/成功/失败/已跳过；成功含得分+会话标识；失败含错误类型+摘要；重启后可读取。
- [ ] FR-4.2 默认跳过成功任务；失败任务可重执行；可清除记录强制重跑。
- [ ] FR-4.3 日志写本地文件、面板可读取尾部；不含账号密码/完整凭据；按时间追加不覆盖。

**FR-5 题库汇聚**
- [ ] FR-5.1 采集覆盖可见相关任务；按题干去重；多来源合并不丢解析。
- [ ] FR-5.2 导出 HTML/Markdown/JSON 三格式；HTML 支持关键词筛选与展开；MD 适合打印；JSON 字段完整；导出物不含凭据。
- [ ] FR-5.3 HTML 图片正常显示；MD 图片题明确标记。

**FR-6 可视化**
- [ ] FR-6.1 总览含任务总数/已完成/平均分/满分数/失败数、总体与各章完成率、每套得分、日志尾部；刷新 ≤10s。
- [ ] FR-6.2 记录页支持文件名/章节/备注搜索、状态筛选、CSV 导出、失败可读摘要。
- [ ] FR-6.3 题库页支持关键词搜索、题型筛选、点击展开答案解析、正确选项明确标识。
- [ ] FR-6.4 主流程启动后面板立即可用；展示完整任务计划（含待执行）；关闭面板后台不中断。

**FR-7 安全与隐私**
- [ ] FR-7.1 密码不回显/不写日志/不进导出物；配置文件被忽略；文档无真实账号密码示例。
- [ ] FR-7.2 面板仅监听回环地址；数据默认本地、不主动上传第三方。

### C. 合规与视觉验收
- [ ] 界面文案为复习导向，无"刷分"类措辞；无绕过监考/伪造成绩/规避规则的设计或入口。
- [ ] UI 为学术简洁风：黑白灰 + 细线、无渐变/大色块/彩色标签；状态色默认关闭。
- [ ] 表格与题目解析区可选中复制、打印友好。
